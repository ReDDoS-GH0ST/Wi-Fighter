📌 Wi-Fighter - это кроссплатформенный инструмент для аудита сетевой безопасности ранее подключенных Wi-Fi сетей. Программа написана на Python с использованием библиотек rich, prettytable и termcolor для комфортного использования
<hr>
⚠️ <strong>ВНИМАНИЕ!!!</strong> Используйте программу исключительно в <b>ОБРАЗОВАТЕЛЬНЫХ</b> целях в своей домашней лаборатории! Использование такого инструмента для злонамеренных целей карается юридическими последствиями! <u>Автор не несёт ответственности за неправомерное использование!</u>
<hr>
<p>💎 Возможности Wi-Fighter:</p>
<ul>
  <li>Кроссплатформенность (Работает на Windows и Linux)</li>
  <li>Сканирование и получение таблицы найденных Wi-Fi сетей</li>
  <li>Извлечение и вывод данных Wi-Fi сети (только для ранее подключенных!)</li>
  <li>Автоматизированная проверка root-пользователя перед запуском (для Linux)</li>
  <li>Вывод баннера и таблицы доступных команд</li>
  <li>Выход из программы (командой или сочетанием клавиш Ctrl+C)</li>
</ul>
<hr>
<p>📦 Требования:</p><ul>
  <li>Для Linux - Права root-пользователя перед запуском</li>
  <li>Python 3.7 или выше</li>
  <li>Библиотеки: rich, prettytable, termcolor</li>
</ul>
<hr>
<p>⚙️ Установка:</p>
<p>Если вы запускаете программу на Linux - обязательно запускайте от имени root-пользователя</p>
<p>Для Windows:</p><ol>
  <li>Скачайте репозиторий</li>
  <li>Установите библиотеки, введя следующую команду в терминале или в командной строке: <code>pip install -r "Путь/к/файлу/requirements.txt"</code></li>
  <li>Запустите командную строку или терминал и запустите программу, введя команду: <code>python "Путь/к/файлу/Wi-Fighter.py"</code></li>
  <li>Готово!</li>
</ol>
<p>Для Linux:</p><ol>
  <li>Откройте терминал</li>
  <li>Введите команды:</li>
     <code>git clone https://github.com/ReDDoS-GH0ST/Wi-Fighter.git</code><br>
     <code>cd Wi-Fighter</code></li>
  <li>Установите библиотеки, введя следующую команду в терминале: <code>pip install -r "Путь/к/файлу/requirements.txt"</code></li>
  <li>Запустите терминал и запустите программу, введя команду: <code>sudo python "Путь/к/файлу/Wi-Fighter.py"</code></li>
  <li>Введите пароль от root-пользователя и нажмите Enter</li>
  <li>Готово!</li>
</ol>
<hr>
<p>🛠 Использование:</p>
  <p>Используйте допустимые команды:</p><ol>
    <li><code>scan</code> - для сканирования и получения найденных Wi-Fi сетей</li>
    <li><code>showinfo</code> - для извлечения и вывода данных Wi-Fi сети (только для ранее подключенных!)</li>
    <li><code>help</code> или <code>--h</code> - для получения помощи в использовании Wi-Fighter</li>
    <li><code>clear</code> - для очищения терминала</li>
    <li><code>banner</code> - для вывода баннера</li>
    <li><code>quit</code>, <code>exit</code> или <code>Ctrl+C</code> - для выхода из программы</li>
  </ol>
